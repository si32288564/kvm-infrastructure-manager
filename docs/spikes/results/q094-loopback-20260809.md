# Q-094 Loopback Smoke Result — 2026-08-09

- 状態: Preliminary / Non-certifying
- Host: Apple M2 / darwin arm64
- Go: 1.26.5
- grpc-go: 1.83.0
- protobuf-go: 1.36.11
- protoc-gen-go-grpc: 1.6.2
- 対象: gRPC bidirectional stream、typed protobuf stream over HTTP/2

## Functional Contract

両候補で次を確認しました。

- five synthetic module capability を一つの Agent hello/session へ集約
- 1 Agent session あたりの physical TCP/mTLS connection は一つ
- client certificate がない接続を拒否
- typed Envelope の送受信と payload digest 維持
- caller の bounded receive cancellation 後も persistent receive loop と session を継続利用
- server-side connection loss を deadline 前に transport error として検出
- wire adapter が module interface へ HTTP/gRPC type を公開しない

Session Manager 側では、live connection が残っていても Authority View を `FENCED` または新 generation へ更新すると、旧 generation message を module routing 前に拒否することを別 fixture で確認しています。

## Loopback Round-trip

次を 500 ms、3回ずつ実行しました。

```sh
make bench-agent-transport
```

| Candidate | Payload | ns/op range | throughput range | bytes/op range | allocs/op range |
|---|---:|---:|---:|---:|---:|
| gRPC bidi | 1 KiB | 46,289–48,611 | 21.06–22.12 MB/s | 6,386–6,433 | 58 |
| typed HTTP/2 | 1 KiB | 53,692–55,598 | 18.42–19.07 MB/s | 11,010–11,021 | 47 |
| gRPC bidi | 256 KiB | 622,020–892,855 | 293.60–421.44 MB/s | 2,002,004–2,037,819 | 171–179 |
| typed HTTP/2 | 256 KiB | 891,542–915,576 | 286.32–294.03 MB/s | 2,258,702–2,260,350 | 314–318 |

この値は loopback の echo round-trip であり、Gateway processing、PostgreSQL receipt、durable spool、proxy/LB、WAN latency、packet loss を含みません。gRPC はこの条件で低い latency/bytes allocation を示しましたが、これだけで採用しません。

この測定時点の adapter は `Receive()` 呼出しごとに一つの goroutine を生成していたため、scale 比較の正本にはしません。その後、両候補を一つの per-session persistent receive loop へ変更し、結果を [Q-094 1,000-session Scale Result](q094-scale-20260809.md) に分離しました。

## Decision Status

`HOLD`です。次を同一 fixture で完了するまで Q-094 を Close しません。

- large bulk frame 送信中の Result/Lease HOL latency
- bounded bulk service guarantee の scale measurement
- reconnect storm と Gateway admission/backoff
- credential renewal 時の old/new session handoff
- Envoy/HAProxy 等の supported proxy/LB behavior
- durable spool、resync、response loss、Gateway restart
- 100/1,000/10,000 session の resource model
- dependency/SBOM/security update comparison
